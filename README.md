# School Management System

A production-ready School Management System built with Django REST Framework and React.

## 🚀 Tech Stack

### Backend
- Python 3.13
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication

### Frontend
- React
- Tailwind CSS
- Axios

## 📦 Features

- Authentication & Authorization
- Student Management
- Teacher Management
- Academic Management
- Attendance Management
- Examination Management
- Fees Management
- Routine Management
- Notice Board
- Notification System
